## 二、屏幕两条购买路线

### 路线 A：README 指路（与上游 PCB 最配套）

上游 README 的指路是：7.3 寸四色屏 EL073TS3（49-pin 裸屏）+ B 站 UP 主「记得带马扎」的 49-pin 七色 EPD 转接板。上游 PCB 的 H4 焊盘就是按这块转接板配套设计的。

步骤：
1. 打开 B 站，搜索 UP 主「记得带马扎」，进入主页。
2. 找墨水屏转接板相关视频，购买入口通常在视频简介 / 主页橱窗（一般挂淘宝链接）。
3. 下单「49-pin 七色转接板」；其店铺通常同时卖配套 49-pin 裸屏（EL073TS3），可一并购买，避免屏与板对不上。
4. 收货确认：转接板上有排座/排针，屏排线是 49-pin 0.5mm 软排线，对插即可，屏与转接板之间不需要焊接。

注意：README 未给直链，具体购买入口以 UP 主主页为准；若橱窗缺货，评论区/粉丝群通常有补货通知。

### 路线 B：自购成品模块（省事，不依赖个人卖家）

直接买微雪（Waveshare）7.3 寸四色墨水屏成品模块，自带驱动转接板与排座，屏幕到手免焊接。

必须核对清单（下单前问客服或看详情页）：
- 尺寸 7.3 寸，分辨率 800×480
- 颜色为四色：黑、白、红、黄（bwry）
- 驱动 IC 为 **GDEY073D46**（与固件 `GxEPD2_730c_GDEY073D46` 一一对应，此项是硬指标）
- SPI 接口成品模块（带转接板，8pin 排座），不是 49-pin 裸屏

渠道：微雪官方淘宝店 / 微雪天猫旗舰店，搜索「微雪 7.3inch e-Paper 四色」。

与路线 A 的差异：微雪转接板的排座线序与马扎板不同，连主板 H4 时按信号名逐根对接（VCC/GND/DIN/CLK/CS/DC/RST/BUSY），不按位置对插。

## 三、主板打板流程（嘉立创）

文件都在 `esp32/pcb/`：`Gerber/`（制板）、`BOM.csv`（物料）、`PickAndPlace.xlsx`（贴片坐标）。

1. 注册嘉立创（jlc.com），下单 PCB：上传 Gerber 文件夹打包 zip → 板层 2 层、厚度 1.6mm、数量 5（免费活动价）。
2. 下单 SMT：上传 BOM.csv + PickAndPlace.xlsx，选经济型贴片，贴装数量选 2 片。BOM 里器件均带立创商城 C 编号，勾选「物料一致性确认」即可配齐。
3. 收板验收：目检 ESP32-S3 模组四角与阻容是否贴正；用万用表量 3.3V 与 GND 是否短路（不熟悉可跳过，烧录时能通电即算过）。

TP4056 说明：它是通孔件（天猫链接），SMT 不贴，需自己焊 5 个脚（大焊盘，容易）。已定电池 + USB 充电路线，此颗必装。

## 五、供电与续航（电池 + USB 充电路线）

每日一刷的耗电模型：清醒约 2~4 分钟（WiFi 连接 + 下载约 370KB bin + 刷屏），均流约 100~150mA；其余 ~23.9 小时深度休眠。上游 README 实测口径：长休眠待机电流 < 1mA，2 节 18650（5000mAh）约半年续航。

- 3.7V 500mAh 小锂电：按上游保守口径（整机待机 ~1mA）约 2~3 周一充；若整机待机优化到 ~0.1mA，可到 1~2 个月一充。
- 3.7V 18650（2000~3000mAh）：约 3~12 个月一充，与上游「半年」口径一致，推荐省心之选。
- 充电：TP4056 走 5V 输入。注意上游 PCB **没有 USB 座**（H2 只是 ESP32 原生 USB 焊盘，可留空不焊），5V 从 H6 焊盘进：最简单是剪一根 USB 线取 5V/GND 焊到 H6；想做成「可插拔」可在改板时加 Type-C 母座（仅供电用途）。500mAh 约 1~1.5 小时充满（默认 1A 充电电流下更快）；18650 约 2.5~4 小时。
